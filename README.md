# Harbourline Creative: Case Facilitation Runbook

BADM 470 case facilitation (Capilano University). A single-page runbook for a 90-minute, discussion-based facilitation of the Harbourline Creative case, structured around the abbreviated case analysis process in Chapter 2 of Anderson, Buengel, & Simpson (2025).

## What it includes

- Run of show with start times, durations, leads and expected class outputs (totals 90 minutes)
- Eleven segments: opening, then steps 1 to 10 of the abbreviated process
- For each segment: purpose, interactive activity, probing questions, a timer, and a notes box
- A line-of-sight tracker that lights up as class outputs are captured
- Session clock and a "Download notes" button

Notes are stored in the browser (localStorage) on the device you use, so run the session from one laptop.

## Publish it with GitHub Pages

1. Sign in at github.com and click **New repository**. Name it `harbourline-facilitation`, set it to **Public**, and click **Create repository**.
2. On the new repo page, click **uploading an existing file**.
3. Drag in `index.html` and `README.md`, then click **Commit changes**.
4. Open **Settings > Pages**.
5. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then click **Save**.
6. Wait one to two minutes and refresh the Pages screen. Your link appears at the top:
   `https://YOUR-USERNAME.github.io/harbourline-facilitation/`
7. Open the link on the facilitation laptop and test the timers before class.

## Customize before class

- Open `index.html` in GitHub, click the pencil icon, and edit the `S` array near the bottom (titles, minutes, activities, questions).
- Commit the change; the site updates within a couple of minutes.
- Check every case fact against the case text, then replace "Member 1–4" with your team's names in the Lead boxes.
